# werbemittel

Kurzzeitige Ablage für Anzeigenbilder und -videos von Praxisstart für Mediziner / Hanna Landener.
Meta holt die Datei über ihre öffentliche Adresse in die Medienbibliothek des Werbekontos,
danach wird sie hier wieder gelöscht (auch aus dem Verlauf). Hier liegt nur Material, das für
Anzeigen bestimmt ist: keine Kundendaten, keine erkennbaren Teilnehmenden.
